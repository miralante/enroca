# Security

The latest published Enroca version is maintained. Report security issues privately
to hello@apptonomia.uk, with reproduction steps and no personal data or credentials.
Do not disclose details publicly before agreeing on a resolution.

Enroca has no accounts, backend or telemetry. It uses own-origin resources and
validated local storage. _headers defines CSP and permissions. Games restore
from legal moves. Deletion only affects enroca: keys.
