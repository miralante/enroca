# Seguridad

Se mantiene la última versión publicada de Enroca. Comunica problemas de seguridad
de forma privada a hello@apptonomia.uk, con pasos de reproducción y sin datos
personales ni credenciales. No publiques detalles antes de acordar su resolución.

Enroca no tiene cuentas, backend ni telemetría. Solo usa recursos propios y
almacenamiento local validado. _headers define CSP y permisos. La partida se
reconstruye desde jugadas legales. El borrado afecta solo a claves enroca:.
