# Ludia

En Inicio, elige un juego.
En Reglas, descubre una idea cada vez.
Pulsa Ver la jugada para mirar el ejemplo.
En Ejercicios, prueba una acción. Puedes pedir una pista.
La respuesta queda visible hasta pulsar Siguiente.
En Jugar, elige las opciones y empieza tu partida.

Puedes continuar una partida guardada desde Jugar.
Cada juego guarda su propia partida.
Deshacer permite volver a una jugada anterior.
Tetris empieza paso a paso. La caída automática es opcional y tiene pausa.
En Dominó con dos personas, pasa el dispositivo antes de mostrar las fichas.

Ajedrez conserva sus temas, ejercicios, retos y partidas.
En Ajustes puedes cambiar idioma, texto, contraste, nombres de piezas y sonidos.
El sonido empieza apagado. Los datos quedan en este navegador.
