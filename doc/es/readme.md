# Enroca

En Inicio, toca «Conoce el tablero».
Mira el ejemplo y pulsa Siguiente.
Después, toca la casilla que se indica.
Puedes pedir una pista o volver al ejemplo.

En Retos hay banderas, caminos y capturas.
En Partida eliges las piezas y el rival.
No hay reloj.

En Ajustes puedes cambiar el texto, el idioma, el contraste y los nombres de piezas.
Los sonidos son opcionales. Tus avances se quedan en este navegador.
