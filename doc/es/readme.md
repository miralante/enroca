# Juega con Enroca

Abre la aplicación.
Elige Aprende.
Mira una lección.
Pulsa Escuchar si prefieres oírla.
Prueba sus ejercicios.
Puedes pedir una pista.
Después, elige Juega.
Puedes volver a cualquier paso.
No hay reloj.

En Ajustes puedes cambiar el texto, el idioma y el contraste.
Tus avances se quedan en este dispositivo.
