# Abrir Enroca

- Archivo: abre index.html. Todas las actividades funcionan sin servidor.
- ZIP: descarga y extrae la carpeta completa; después abre index.html.
- Python: python scripts/serve.py, dentro de la carpeta.
- Node: node scripts/serve.js; después abre http://127.0.0.1:8099/.

La PWA necesita localhost o HTTPS. Visita una vez con conexión para guardar los
archivos. En el navegador puedes instalarla. El dominio público previsto todavía
requiere aprobación, provisión y despliegue; ver CLOUDFLARE.md.
