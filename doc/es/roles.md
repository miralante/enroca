# Roles

**Persona usuaria:** decide qué aprender, pide ayuda y controla su ritmo.
**Apoyo:** familia, docente o profesional que acompaña sin sustituir decisiones.
**Construcción:** mantiene contenido, código y pruebas según CLAUDE.md.

El diseño considera discapacidad intelectual; esa descripción se limita a documentación
interna. La interfaz no etiqueta ni compara a las personas.
