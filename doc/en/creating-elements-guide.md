# Create a lesson

1. Choose one rule and a stable ID in data.js.
2. Explain it in short steps and translate both languages.
3. Add a diagram, destinations and a valid movement example.
4. Add two exercises: recognition and application. Link them to the lesson.
5. Explain with a hint; avoid trick questions and complex negative statements.
6. Run check.js and review reading and moves with a supporter.

No rankings, streaks, artificial urgency or persuasion techniques. Motivation comes
from learning a useful move and retaining control. New positions require checking
that alternative valid answers are not incorrectly rejected.
