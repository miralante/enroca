# Open Enroca

- File: open index.html. All activities work without a server.
- ZIP: download and extract the whole folder, then open index.html.
- Python: python scripts/serve.py from the app directory.
- Node: node scripts/serve.js, then open http://127.0.0.1:8099/.

PWA installation requires localhost or HTTPS. Visit once while connected to cache
the files. Use the browser’s installation option. The intended public domain still
requires approval, provisioning and deployment; see CLOUDFLARE.md.
