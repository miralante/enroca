# Enroca

On Home, select “Meet the board”.
Look at the example and select Next.
Then tap the square named on screen.
You can ask for a hint or return to the example.

Challenges has flags, paths and captures.
In Match, choose the pieces and opponent.
There is no clock.

Settings lets you change text size, language, contrast and piece names.
Game sounds are optional. Progress stays in this browser.
