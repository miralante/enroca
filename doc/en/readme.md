# Ludia

Choose a game on Home.
In Rules, discover one idea at a time.
Select Show the move to see the example.
In Exercises, try an action. You can ask for a hint.
Feedback stays visible until you select Next.
In Play, choose your options and start a match.

You can resume a saved match from Play.
Each game keeps its own match.
Undo lets you return to an earlier move.
Tetris starts step by step. Automatic falling is optional and has a pause button.
In two-person dominoes, pass the device before showing your tiles.

Chess keeps its topics, exercises, challenges and matches.
Settings includes language, text size, contrast, piece names and sounds.
Sounds start off. Data stays in this browser.
